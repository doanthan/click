A small status marker - quieter than Tag. Use for status badges ("Almost full", "New", "You're going"), date pills over event imagery, and "Mutual" flags.

```jsx
<Badge tone="coral">Almost full</Badge>
<Badge tone="onImage">Sat 21 Jun · 6:30pm</Badge>
```

Tones: `neutral`, `purple`, `lavender`, `coral`, `amber`, `sage`, `teal`, `onImage` (translucent for over imagery). Status colours appear on badges only - never as a CTA.
