An overlapping cluster of avatars with an overflow count and optional label - the Who's-going social proof on event cards. Only render at ≥3 people (product privacy threshold).

```jsx
<AvatarStack people={["Mia","Jules","Sam","Priya","Tom"]} label="12 going" />
```

Props: `people` (names or {name, src}), `max`, `size`, `label`.
