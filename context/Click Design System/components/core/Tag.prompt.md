Interest / category chip. ONE neutral look on every surface - white fill, Mist hairline, Ink text, no dot - so it always reads as a tag and never re-tints per surface. Pill shape, ~28px (dense 24px), label 13/500. The only purple tag is `selected` (Deep Purple fill + leading check), for onboarding grids and filters. Status colour never goes on a tag - that's Badge.

```jsx
<Tag>Ceramics</Tag>
<Tag dense>Natural wine</Tag>
<Tag selected onClick={toggle}>Pottery</Tag>
```
