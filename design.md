# Click - Design System (DESIGN.md)

Generated from the live code so agent tooling (impeccable, etc.) reads the CURRENT
system. The full canonical spec is **`context/Click Design System/`** (claude.ai/design
export - never hand-edit) with `context/DESIGN.MD` as the palette canon; tokens are
mirrored into `src/app/globals.css`. When this file and the bundle disagree, the
bundle wins. Invoke the `click-design` skill before designing or restyling any UI.

> The previous version of this file described the retired pre-DS direction
> (Indigo `#340068`, Bubblegum Pink, Icy Aqua, serif headings). That palette is
> DEAD - do not reintroduce it.

## Identity

Click is a Sydney events platform where people meet through real-world events and
a private, mutual "click" mechanic. The feel: a warm party invitation designed by
a careful studio - candid photography, cream paper, one deep purple, soft purple
shadows. Register: brand on marketing surfaces (`/`, `/how-it-works`), product
everywhere signed-in.

## Color (tokens in `src/app/globals.css` - always `var(--token)`, never hex)

- **Deep Purple `#3B2F81`** (`--purple`, and the historic accent alias `--rose`)
  is the ONLY primary-action / selected colour. Flat - never a gradient, never a
  glow. Hover `--purple-hover #332873`, press `--purple-press #2A2160`.
- Page ground: Cream `--champagne #F9F6F0` (never stark white pages). Cards:
  white `--paper`. Text: Ink `--ink #1C1830`; secondary `--slate #6B6580`;
  faintest meta `--ink-faint`.
- Lavender `--lavender #C8B8F8` is an accent on SMALL surfaces only; the only
  large-section tint is `--lav-bg #F0ECF4`.
- Status colours live on BADGES ONLY, never CTAs or hero accents: coral
  `--coral` (almost full), amber `--amber` (waitlist/trending), sage `--sage`
  (going/mutual/free), teal `--teal` (new). Small status text uses the
  `--*-ink` AA variants. Destructive is `--danger #B5362F`, never coral.
- Deep bands: `--surface-deep #201A3A` (aubergine-ink) with `--on-deep` cream
  foreground - reserved for the few anchor moments (homepage closer, "Join
  once" style bands). Not a general dark theme; the DS is light-only.
- Hairlines: `--line` / `--mist`; borders quiet and purple-tinted.

## Typography

- Display: **Poppins** (`--font-click-display`, via next/font) - headings H1-H3,
  wordmark, button labels, big numbers. SemiBold 600 default (H1 may go 700).
- Body: the **system font stack** (`--font-click-body`). Paragraphs are NEVER
  Poppins; headings are never body-stack.
- Fluid scale tokens: `--text-display` (32→64), `--text-h1` (28→40), `--text-h2`,
  `--text-h3`, `--card-title`. Body stays flat 16px (iOS zoom guard).
- `.eyebrow` is the one overline voice (system 600 micro-caps, slate, leading
  rule). Use sparingly - never an eyebrow above every section.
- Numerals that align in columns get `tabular-nums`.

## Shape, elevation, layout

- Buttons `.ck-btn`: radius 12 (`--radius-md`), NEVER pills. Pills belong to
  tags (`.ck-tag`) and avatars. Badges `.ck-badge`: ~8px rounded rects. Cards:
  `--radius-lg`/`--radius-xl` (16-20).
- Shadows soft, low, purple-tinted (`--shadow-xs..lg`, `.hard-shadow*`) - never
  a glow.
- The one container: `.ck-page` (max 1200px, shared LEFT EDGE on every page,
  header and footer included). Narrow pages cap width and let whitespace fall
  to the RIGHT.
- Footer is deliberately two quiet rows on cream - the fat dark footer band was
  retired by rule; do not bring it back.

## Motion

- Voice: soft and physical. Pure-CSS load cascade (`.rise-soft` + `.rise-d1..6`),
  scroll reveals via the `<Reveal>` island (`.reveal`, progressive enhancement -
  content is never gated on JS), `.pop-in` polaroid toss (deliberate overshoot -
  the party signature), `.nudge-arrow` for arrow links, one marquee max per page
  (`.marquee`, pauses on hover).
- `prefers-reduced-motion` is handled GLOBALLY in globals.css; JS-driven effects
  (canvas-confetti via `fireBrandConfetti`) carry their own explicit guard.
- Confetti is reserved for genuine success/party moments (persona saved, the
  hero invite sticker) - never ambient.

## Imagery

Candid, film-graded Sydney photography generated by the `/images` studio
(`src/lib/image-gen.ts`; homepage set re-rolled via
`node scripts/gen-home-images.mjs`). Polaroid frames (`.polaroid`) present them
as prints. No stock-photo gloss, no AI-slop tells, no abstract gradient art.

## Language (binding - from `context/Click Design System/uploads/CLICK_LANGUAGE.md`)

- It's a *mutual click*, never a "match". Always "click *with*", never "click
  on". "click" is never a UI verb - use tap/select.
- Capital **Click** = the platform; lowercase **click** = the feeling.
- No deficit framing (lonely, struggling) and no loss framing (expires, last
  chance).
- Hyphens ` - `, never em-dashes. In copy, comments, docs - everywhere.

## Mobile-first (retained rule set - still binding)

~80% of users are on phones. Design at 375px first and scale up. Single column
by default; touch targets ≥44px; primary actions thumb-reachable; the mobile nav
is `MobileBottomNav` (desktop header links are `hidden lg:flex`); no horizontal
scroll on the page body (wide content gets its own `overflow-x-auto`); forms
one-handed with sticky primary actions; respect `env(safe-area-inset-*)`.
